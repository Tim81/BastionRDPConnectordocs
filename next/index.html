Your VM has no public IP. Connect to it anyway.

Pick a virtual machine, or type an address. The remote desktop client you already use opens the session through Azure Bastion. Nothing is exposed to the internet.

Same Bastion host, same API the portal's Connect button uses. The session arrives in mstsc instead of a browser tab.

What you get

The application talks to the Bastion and Azure Resource Manager APIs directly. There is no dependency on Azure CLI and no separate runtime to install.

2-4s

Find a VM across every subscription

Virtual machines across 200 subscriptions load in a few seconds, using the Azure Resource Graph. Search needs three characters.

0

Firewall rules to open

Your computer makes one outbound connection on 443. Nothing inbound, no public IP on the VM, no certificates to manage.

1

File to run

A single self-contained executable. No installer, no admin rights, no .NET runtime to add first.

2

Ways to connect

A tunnel through a local port reaches any address in the virtual network. RD Gateway is the shorter path for Azure VMs.

6

Languages

English, Dutch, German, French, Spanish and Portuguese, switched while the application is running.

5

Reconnect attempts

If the tunnel drops, it reconnects on its own with a widening gap. An open session survives a short outage.
